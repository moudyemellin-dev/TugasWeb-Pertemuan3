# Tugas Rutin 3 Pemrograman Web

## Katalog Produk Responsif

Website katalog produk responsif menggunakan Bootstrap 5.

## Teknologi

- HTML5
- CSS3
- Bootstrap 5

## Fitur

- Mobile-first approach
- Responsive Navbar
- Hamburger Menu
- Responsive Product Grid
- Product Card
- Responsive Images
- CSS clamp() Typography
- Footer
- Responsive Breakpoints

## Responsive Grid

- Mobile: 1 kolom
- Tablet: 2 kolom
- Laptop: 3 kolom
- Desktop: 4 kolom

## Testing

Website diuji pada:

- Mobile: 375px
- Tablet: 768px
- Desktop: 1440px
